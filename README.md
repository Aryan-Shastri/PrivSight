# PrivSight

Privacy-before-network browser agent for SIH26171. Chrome MV3 observes locally, tokenizes sensitive text, masks sensitive pixels, enforces a fail-closed egress boundary, and accepts only one constrained planner action. The default planner is deliberately labelled **MOCK PLANNER**; real Qwen/vLLM is optional.

Implementation status and commands are documented in `docs/implementation-status.md` and `docs/demo-runbook.md`.
