    Privacy boundary

    The model receives less—not everything.

    Stored locally

    Plaintext aliases live only in a short-lived vault bound to the session, tab, origin, role, and expiry.

    Transmitted

    Only bounded semantic JSON and an irreversibly masked image with verified SHA-256 binding.

    Rejected

    Raw DOM, raw screenshots, credentials, cookies, query strings, unknown fields, stale targets, and arbitrary actions.

    Fail-closed by default.

    Hash mismatch, missing confirmation, stale target, unknown action, or unverifiable result stops the run.
